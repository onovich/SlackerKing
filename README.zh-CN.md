# SlackerKing

[English](README.md)

在理政、享乐和夜间结算间平衡国库、权威、军力、民心与压力的宫廷生存游戏。

![SlackerKing 封面](docs/cover.png)

**[在线体验](https://onovich.github.io/SlackerKing/)**

## 项目包含什么

- 早晨处理政务。
- 下午选择享乐。
- 夜间统一结算。

## 快速开始

安装依赖并启动本地版本：

```bash
npm install
npm run dev
```

仓库还提供 `npm run build`。

## 仓库结构

- `src/` — 应用与库的源代码。
- `docs/` — 项目文档与设计说明。
- `origin/` — 原始原型与设计资料。
- `.github` — 自动化与 GitHub Pages 工作流。
- `index.html` — Web 入口。
