# SlackerKing 执行路线图

## 目标定位

将当前项目从“可运行的黑色幽默生存原型”推进为“短局高复玩、信息可读、路线清晰的叙事策略小品”。

核心方向：

- 强化玩家对局势的理解与预判能力。
- 重构数值职责，让每种选择都对应明确的治理风格。
- 扩充派系、角色与事件链，提升中长期目标感。
- 补齐重玩驱动与基础功能，支撑持续迭代。

## 执行原则

- 先补信息可读性，再重做数值，再扩内容。
- 优先解决玩家“看不懂为什么输”的问题，而不是先堆事件数量。
- 每个阶段都必须形成可验证产物：文档、规则表、数据表或可试玩改动。
- 保持短局体验，避免把项目拉向重度策略模拟。

## 里程碑

### 阶段 1：信息可读性与体验基线

目标：让玩家清楚知道当前压力点、潜在危机和主要策略方向。

交付物：

- 风险与预警系统文档。
- UI 信息层重构方案。
- 玩家阶段目标和引导文案草案。
- 第一批实现任务清单。

验收标准：

- 玩家能够从界面中识别高风险资源和正在升温的危机。
- 夜间结算能解释“发生了什么、为什么发生、还有没有补救机会”。
- 午后情报行为不再只是读 flavor log，而是明确提供策略价值。

### 阶段 2：数值职责重构

目标：重新定义资源、精力、压力、行动地点、危机阈值之间的关系。

交付物：

- 资源与角色状态设计表。
- 晨间选项收益/成本分层规则。
- 午后地点设计表与风险收益模型。
- 夜间危机阈值与预警层规则表。

验收标准：

- 不同午后地点形成明确定位，不再有绝对标准答案。
- 晨间高代价选项提供可感知的回报，高风险后果具备预警层。
- 新玩家前 3 到 5 天能建立理解，之后才逐步进入高压状态。

### 阶段 3：派系与事件链扩充

目标：把随机单事件升级为可理解、可追踪、可反复尝试的派系叙事链。

交付物：

- 四条核心派系线：旧贵族、军方、商会、外敌。
- 5 到 8 名持续登场角色设定。
- 晨间事件扩充表。
- 午后地点衍生事件表。
- 夜间危机扩充表。

验收标准：

- 玩家能明确感知自己在偏向哪条路线。
- 主要事件不再只靠随机抽样支撑内容时长。
- 同一局中会出现连续性的政治后果，而不是完全离散的小故事。

### 阶段 4：重玩驱动与基础功能

目标：提升长期留存和重复开局动力。

交付物：

- 自动保存与继续游戏方案。
- 结局图鉴与死法记录方案。
- 最长存活、路线称号、结算页方案。
- 后续音效、成就、演出优化 backlog。

验收标准：

- 玩家死亡后有明确的“再开一局试另一条路”的驱动力。
- 项目具备原型之外的基础留存能力。

## 当前推进顺序

1. 完成阶段 1 与阶段 2 的规格文档，并完成对应实现闭环。
2. 把内容扩张先收敛为“派系路线可见化”的最小骨架。
3. 让晨间选项和午后地点开始持续推动派系倾向。
4. 在路线骨架稳定后，再补角色、事件链和派系权重事件池。

## 当前决策

- 不先大规模扩事件文本，先解决信息反馈与系统表达。
- 不先做大规模美术翻新，延续现有视觉方向。
- 文档先服务实现，不写泛泛而谈的长篇设定。
