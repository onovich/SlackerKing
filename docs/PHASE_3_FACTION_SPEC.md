# 阶段 3 规格：派系路线与事件链扩充

## 阶段目标

第三阶段的核心不是单纯增加事件数量，而是把当前这些分散的选择，逐步组织成玩家可理解的政治路线。

玩家需要开始明确感知：

- 自己正在向哪股势力靠拢。
- 当前这条路线会更容易触发哪些事件。
- 自己付出的代价，不只是数值波动，而是长期的宫廷站队。

这一阶段完成后，游戏体验应从“每天处理一个随机麻烦”升级为“我正在把王朝推向某种统治风格”。

## 当前版本的问题

### 1. 事件有主题，但缺少连续政治归属

- 玩家能看懂单个事件在讲什么。
- 但还不能直观看出自己是在押旧贵族、军方、商会还是外邦路线。

结果：

- 每次选择更像局部止损。
- 玩家较难形成“这一局我要走哪条线”的目标感。

### 2. 派系影响只体现在资源与隐患上

- 当前资源和风险系统已经能解释短期后果。
- 但派系支持度还没有作为长期状态被表达出来。

结果：

- 中局缺少政治积累感。
- 事件后果难以自然串成连续链条。

### 3. 扩内容还缺一个统一挂点

- 现在已经有晨间事件、午后地点、夜间危机三层结构。
- 但如果继续加内容，没有一个统一的“路线变量”来承接新事件条件。

结果：

- 后续内容容易继续做成离散小故事。
- 新事件之间很难互相呼应。

## 设计原则

- 派系倾向先做“路线显示器”，再做更重的派系结算。
- 先让玩家知道自己在偏向谁，再让系统因此改变事件池。
- 派系是中期状态，不应在一两次选择后立刻锁死路线。
- 事件文本扩写要服务于派系链，而不是只追求花样数量。

## 四条核心派系线

### 旧贵族

定义：礼制、婚盟、王室正统性与传统统治秩序。

当前可承接选择：

- 王后寝宫。
- 仔细批阅政务。
- 强硬压制宰相夺权。
- 把珍奇异兽留作王室象征。

后续方向：

- 引入王后、宗室长者、礼官、保守派领袖等持续角色。
- 提供稳权威、稳民心、慢节奏修复型事件链。

### 军方

定义：将军、禁卫、边军与强硬镇压能力。

当前可承接选择：

- 皇家猎场。
- 铁血镇压。
- 斩首使者。
- 借刀扶持军方权臣。

后续方向：

- 引入边军主帅、城防将领、禁卫统领。
- 提供补军力、压危机，但可能加速财政消耗与民怨的事件链。

### 商会

定义：逐利商人、包税人、权贵代理人与投机网络。

当前可承接选择：

- 分宰相的盐业专卖收益。
- 把异兽卖给黑市。
- 通过享乐与买单换取短期舒适。
- 草率放行政令，给投机者留套利空间。

后续方向：

- 引入盐商、金融掮客、黑市头目、宫廷总管。
- 提供补国库、拖延危机，但侵蚀权威与民心的事件链。

### 外邦势力

定义：使团、边境强权、外部压力与外交交易。

当前可承接选择：

- 糊弄、拖延或买通汗国使者。
- 借情报行动拖延边境危机。

后续方向：

- 引入汗国使臣、边关督抚、联姻对象、外敌密探。
- 提供拖时间、换和平或转嫁风险的事件链。

## 规则骨架

### 派系倾向值

- 每次晨间选择或午后地点，都可对一到两个派系产生倾向值。
- 派系倾向先采用轻量累积，不做复杂衰减。
- 当前建议分层：
  - 0：观望
  - 1 到 2：试探
  - 3 到 4：靠拢
  - 5 以上：押注

### UI 表达目标

- 桌面端需要有“Faction Drift”区块，让玩家知道自己在靠近谁。
- 当某一派系进入“靠拢”后，阶段目标提示可开始提醒玩家兑现路线红利。
- 没有明显路线时，要明确提示“你还没下注”。

### 内容挂接方式

- 晨间事件通过 choice 的 factionEffects 字段接入。
- 午后地点通过 location 的 factionEffects 字段接入。
- 后续事件条件可基于派系倾向值和当前风险共同决定。

## 第一批落地产物

本轮先完成以下最小闭环：

- 派系元数据表。
- 派系倾向值写入游戏状态。
- 晨间选项与午后地点接入 factionEffects。
- 桌面面板显示当前派系偏移。
- 路线图与 README 补充阶段 3 文档入口。

这批内容的目标不是立即增加大量文本，而是把后续扩内容的骨架搭起来。

## 后续实现顺序

1. 先补 2 到 3 个能明显响应派系倾向的新晨间事件。
2. 为四条派系线各补至少 1 个持续角色。
3. 让派系倾向开始影响事件池权重，而不是只做展示。
4. 再补夜间危机与结局页中的路线总结。

## 验收标准

- 玩家能在第 3 到 5 天明确看出自己正偏向哪条路线。
- 当前路线能通过 UI 提示而非纯记忆推断。
- 新内容扩展时，不需要再临时发明平行状态表，而是直接挂接派系倾向系统。
